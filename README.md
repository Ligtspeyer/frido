# Orlando Frido Siebert / Dagma Doppel D

A static portfolio and visual archive. Open `index.html` in a browser, or serve this directory with `python3 -m http.server` and visit `http://localhost:8000`.

The 20 visual chapters are curated in `app.js`; `artworks.js` lists the original image filenames, and `thumbnails/` contains smaller previews for the gallery tiles. Project links use URL hashes, so they also work on static hosting without server-side routing. The persona switch is saved locally when browser storage is available.
